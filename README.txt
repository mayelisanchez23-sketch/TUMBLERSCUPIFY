CUPIFY · GitHub Pages Edition
==============================

Esta versión está adaptada para trabajar directamente con GitHub Pages usando:

- index.html
- css/styles.css
- js/main.js
- images/

No necesita React, Next.js, npm ni compilación.

Para publicarla:
1. Sube el contenido de esta carpeta a la raíz del repositorio "cupify".
2. En GitHub: Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /(root).
6. Guarda y espera a que GitHub Pages termine el despliegue.

El carrito usa localStorage, por lo que conserva sus artículos al recargar.
El personalizador guarda el nombre escrito como una primera demostración.
